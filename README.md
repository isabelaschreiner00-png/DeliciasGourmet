#  Projeto Integrador II - Grupo 05

## 📖 Sobre o Projeto

Este repositório contém o desenvolvimento do **Projeto Integrador II**, realizado pelos alunos do **2º semestre**.

O projeto tem como objetivo aplicar os conhecimentos adquiridos ao longo do semestre por meio da criação de uma solução web para um cliente real.

A empresa escolhida foi a **Delícias Gourmet**, para a qual será desenvolvido um **site dinâmico**, buscando modernizar sua presença digital, facilitar a divulgação de produtos e melhorar a experiência dos clientes.

---

## 🎯 Objetivo

Desenvolver um site dinâmico que atenda às necessidades da empresa **Delícias Gourmet**, oferecendo uma plataforma moderna, intuitiva e responsiva para apresentação da empresa, seus produtos e demais funcionalidades definidas durante o levantamento de requisitos.
